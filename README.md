# Promise & Practice — Unit Two (STUDENT edition)

Self-contained, offline-ready GitHub Pages site, organized chapter by chapter.
`index.html` is the student hub. The summative exam is password-locked.

## Easiest deploy (avoids GitHub's 25 MB web-upload limit): GitHub Desktop
1. Install GitHub Desktop (desktop.github.com), sign in.
2. File → Clone repository → your repo → Clone.
3. Copy everything inside this folder into the cloned repo folder.
4. Commit to main → Push origin.
5. On github.com: Settings → Pages → Branch main, folder / (root) → Save.

(The web uploader rejects files over 25 MB and chokes on the zips; GitHub Desktop
pushes everything in one go. Or unzip and upload the folders — every page is under 25 MB.)
